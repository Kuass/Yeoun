## 여운 0.3.0

여운의 첫 공개 Android 릴리스입니다. Android 8.0 이상에서 사용할 수 있습니다.

- Spotify 위에 표시하는 동기화 가사와 자연스러운 줄 전환
- 번역, 발음, 곡별 싱크 설정과 로컬 싱크 제작
- 전체 화면 가사, 재생 조작, 선택적 YouTube 배경과 AI 곡 설명
- 한국어·영어 UI 및 LGPL 2.1 소스 공개

**설치:** `Yeoun-0.3.0.apk`를 내려받아 설치한 뒤 알림 접근과 다른 앱 위에 표시 권한을 허용해 주세요. 번역과 발음에는 본인의 AI API 설정이 필요합니다.

기존 개발용 디버그 APK와 릴리스 APK는 서명이 다릅니다. 디버그 버전 위에 바로 업데이트할 수 없으며, 기존 앱을 삭제하면 기기 안의 설정과 저장한 로컬 가사도 삭제됩니다. 공개 버전을 설치하려고 기존 데이터를 무작정 삭제하지 마세요. 앞으로의 공개 릴리스는 같은 릴리스 키로 서명합니다.

## Yeoun 0.3.0

The first public Android release of Yeoun. Requires Android 8.0 or later.

- Synchronized Spotify lyrics overlay with continuous line transitions
- Translation, pronunciation, per-track offsets, and local lyric timing
- Fullscreen lyrics, playback controls, optional YouTube backgrounds, and AI song notes
- Korean and English interfaces; source under LGPL 2.1

**Install:** Download `Yeoun-0.3.0.apk`, install it, and grant notification access and overlay permission. Translation and pronunciation require your own compatible AI API configuration.

Development/debug APKs use a different signing key and cannot be upgraded directly to this release. Uninstalling an existing app deletes its settings and locally timed lyrics. Future public releases will retain this release signing key.

Provider availability and lyric timing vary by track. Video embedding can be restricted by YouTube or the uploader. AI translations and song notes can be inaccurate. This release does not claim universal device or provider coverage.

`SHA256SUMS.txt` and `signing-certificate.txt` identify the published artifacts. Matching source and license notices are included.
