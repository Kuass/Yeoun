## 여운 0.4.0

- 언어별 해석과 발음 선택, 처음 만나는 언어의 플로팅 안내를 추가했습니다.
- 단어별 발음 배치와 원문·해석·발음의 독립적인 표시 줄 수를 지원합니다.
- LRCLIB 수동 검색, 로컬 LRC 가져오기·내보내기, 줄별 해석·발음 편집을 추가했습니다.
- 설정 프리셋, 개인 가사 백업·복원, 최근 곡과 오프라인 가사를 지원합니다.
- 플로팅 조절 버튼은 이동 후 잠시 표시하며, 가사 창 높이는 부드럽게 변합니다.
- 서비스 시작 시 종료되던 문제와 전체 화면 재생 버튼 모양을 수정했습니다.
- 한국어가 주언어인 곡의 불확실한 짧은 구절은 곡의 문맥을 따르도록 개선했습니다.

**검증:** 단위 테스트 65개가 통과했습니다. 기기 검사와 연결한 휴대폰에서 화면 및 시작 오류를 확인했으며, 실제 AI 출력 품질과 모든 기기의 동작을 보장하는 검증은 아닙니다.
